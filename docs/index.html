🌐เบราว์เซอร์ในตัว

พิมพ์ URL แล้วใช้งานได้เลย มีแถบเครื่องมือของแอปฉีดบนทุกหน้าเว็บ

🎬ตรวจจับวิดีโอ 3 ชั้น

DOM scan + hook fetch/XHR จับ m3u8/mpd + resource timing

🚀เอนจิน yt-dlp + ffmpeg

mp4 / HLS / DASH / YouTube ฯลฯ เลือกคุณภาพได้

📜Log ละเอียด

app.log · downloads.log · events.jsonl ดูในแอปและส่งออกได้

รู้ก่อนติดตั้ง

✅ Windows: ไฟล์เดียวจบ ดับเบิลคลิกได้ทันที ไม่ต้องติดตั้ง Python (ต้องมี WebView2 Runtime — มีในตัว Windows 10/11) · ถ้า Windows Defender SmartScreen เตือนเพราะไฟล์ไม่ได้ sign ให้กด "More info → Run anyway"

✅ Android: ติดตั้งแบบอนุญาต "แหล่งที่ไม่รู้จัก" ตามปกติ · ดาวน์โหลดไฟล์ตรง (mp4/webm/mp3) ได้เต็มรูปแบบ ส่วน HLS/DASH ให้ใช้เวอร์ชันเดสก์ท็อป

🔐 ตรวจไฟล์: ใช้คำสั่ง certutil -hashfile ไฟล์.exe SHA256 แล้วเทียบกับ checksum ที่แสดงข้างบน (ดึงจาก GitHub API / ไฟล์ checksums.txt ของ release)
