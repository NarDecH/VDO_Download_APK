Ext v1.1.0 LATEST EXTENSION แก้ "Failed - Network error" กับวิดีโอ blob:/MSE

แก้ไข Fixed

  • 3 ชั้นสาเหตุของ "Failed - Network error" ถูกปิดหมด: ① chrome.downloads ห้ามส่ง header Referer (โค้ดเดิมใส่ → พังทุกเส้นทาง) ② เส้นทางสำรองเดิมส่ง data: URL ยักษ์ ที่ Chrome ดาวน์โหลดไม่ได้ → เปลี่ยนเป็นประกอบ Blob ใน offscreen document (สตรีม chunk 4MB, cap 800MB) ③ ดาวน์โหลดที่เริ่มแล้วโดน kill ถูกเฝ้าด้วย downloads.onChanged แล้วสลับ fallback อัตโนมัติ
  • player2u.com ใช้ MSE stream (ไม่ใช่ File blob) — เพิ่ม MSE capture: hook MediaSource.appendBuffer เก็บทุก chunk ที่เล่นแล้วประกอบเป็นไฟล์ใหม่
  • ล้างรายการวิดีโอเก่าเมื่อ navigate ใหม่ (blob: URL ตายเมื่อเปลี่ยนหน้า) · readBlob มี XHR fallback

ทดสอบ Tests

  • E2E 20 ข้อ (headless Chrome for Testing + CDP): direct blob/http · force-fallback ผ่าน offscreen assembler · MSE capture ด้วย fMP4 จริง — ทุกข้อตรวจ SHA256 เทียบไบต์ต้นฉบับ
  • แนบ VDOGrabber-chrome-extension-1.1.0.zip ใน release พร้อม checksum ใหม่
Unreleased COMING ส่วนขยาย Chrome — แนบใน release v1.0.0 แล้ว

เพิ่มใหม่ Added

  • ส่วนขยาย Chrome (MV3) — ปุ่มลอย + แผงรายการวิดีโอในทุกหน้าเว็บ, ตรวจจับ 4 ชั้น (DOM scan · hook fetch/XHR ใน MAIN world · resource timing · webRequest observer), popup ต่อแท็บพร้อม logs และท่อดาวน์โหลดหลายชั้น: direct → blob: ตรง → อ่าน bytes ในหน้า → MSE capture (ดัก MediaSource.appendBuffer แล้วประกอบไฟล์)
  • ทดสอบ E2E ด้วย Chrome จริง (Chrome for Testing + CDP) กับหน้าจำลองกลไก blob: ของ player2u.com — ผ่าน 12/12 รวมถึงไฟล์ที่ดาวน์โหลดจาก blob มี SHA256 ตรงกับต้นฉบับทุกไบต์
  • แนบ VDOGrabber-chrome-extension-1.0.0.zip ใน release พร้อม checksum
v1.0.0 LATEST 29 กันยายน 2026 ⬇ ดาวน์โหลด

เพิ่มใหม่ Added

  • Windows Desktop (VDOGrabber.exe) — เบราว์เซอร์ในตัว (Edge WebView2) เปิดหน้าเว็บใดก็ได้ พร้อมแถบเครื่องมือฉีดในหน้า: ตรวจหาวิดีโอ, รายการวิดีโอที่พบ, ปุ่มดาวน์โหลด
  • ตรวจจับวิดีโอ 3 ชั้น — DOM scan (<video>, og:video, JSON-LD, ลิงก์สื่อ) · hook fetch/XMLHttpRequest จับ m3u8/mpd/mp4 · performance resource-timing
  • เอนจิน yt-dlp (bundle ใน exe + อัปเดตตัวเองได้) และ ffmpeg ดาวน์โหลดอัตโนมัติครั้งแรกเมื่อเจอ HLS/DASH
  • เลือกรูปแบบ/คุณภาพ — probe ด้วย yt-dlp -J แสดง resolution / ขนาด / tbr ต่อรายการ
  • ระบบ log ละเอียด 3 ไฟล์ — app.log (RotatingFileHandler 5MB×5), downloads.log (yt-dlp ทุกบรรทัด), events.jsonl (structured) + ตัวอ่าน log ใน Control Center + Export diagnostics (.zip) + crash.log
  • Control Center — แท็บดาวน์โหลด (คิว/ความคืบหน้า/ยกเลิก/เปิดไฟล์), วิดีโอที่ตรวจพบ, Logs, ตั้งค่า, เกี่ยวกับ
  • โหมด --selftest — ทดสอบ headless ครบวงจร: engine, detection JS ใน webview จริง, ดาวน์โหลดไฟล์จริงผ่าน local media server (ใช้ใน CI/หลังแพ็ก exe)
  • แพ็กไฟล์เดียวด้วย PyInstaller — พร้อมไอคอน (.ico หลายขนาด) และ version resource — ผู้ใช้ไม่ต้องติดตั้ง Python
  • แอป Android (Kotlin) — WebView browser, ตรวจจับวิดีโอฉบับเดียวกัน + sniff ระดับ native (shouldInterceptRequest), ดาวน์โหลดผ่าน DownloadManager ลง Downloads/VDOGrabber, ตัวอ่าน log ในแอป, รับลิงก์ที่แชร์เข้ามา
  • GitHub Actions workflow — ปั่น APK ทุก push/PR และแนบ release พร้อม SHA256 + อัปเดต checksums.txt เมื่อแท็ก
  • หน้าเว็บดาวน์โหลดบน GitHub Pages — ดึง release ล่าสุดจาก GitHub API อัตโนมัติ พร้อมปุ่มดาวน์โหลดและ checksum ที่ก๊อปได้
  • เอกสาร md + html ครบชุด (README / RESEARCH / CHANGELOG) พร้อมไดอะแกรม SVG และสกรีนช็อต
  • AGENT.md — คู่มือสำหรับ AI agent/ผู้ดูแล: แผนที่ repo, กติกา, ขั้นตอน release, เคล็ดลับดีบัก
ข้อจำกัดที่ทราบ (Known issues): ไม่รองรับ DRM; เนื้อหาหลังล็อกอินบางประเภทใช้ไม่ได้ (ไม่มี cookie profile) · Android ยังไม่รวมไฟล์ HLS/DASH — แนะนำใช้เดสก์ท็อป (roadmap: ฝัง youtubedl-android) · โฟลเดอร์ code/ (ส่วนขยายต้นแบบที่ minify) ถูก gitignore — มีแต่ในเครื่องผู้พัฒนา

เวอร์ชันถัดไป (roadmap): ฝัง yt-dlp บน Android (youtubedl-android) · รองรับ playlist/queue หลายรายการ · โหมด cookie นำเข้าเพื่อเนื้อหาสมาชิก · desktop workflow บน CI
