VDO Grabber ออกแบบจากการวิเคราะห์ส่วนขยาย "Video Download Helper" — มาพร้อมเบราว์เซอร์ในตัว, ตรวจจับวิดีโอ 3 ชั้น, เอนจิน yt-dlp + ffmpeg และระบบ log ละเอียดสำหรับดีบัก ทั้งไฟล์ exe เดียวบน Windows และแอป Android

⬇ ดาวน์โหลดเวอร์ชันล่าสุด วิเคราะห์ต้นแบบ (RESEARCH)

01มันทำอะไรได้บ้าง

🌐 เบราว์เซอร์ในตัว

พิมพ์ URL ได้เลย แอปฉีดแถบเครื่องมือของตัวเองไว้บนทุกหน้าเว็บ (Shadow DOM แยกสไตล์จากเว็บ) พร้อมปุ่มย้อน/ไป/รีโหลด/ค้นหา

🎬 ตรวจจับวิดีโออัตโนมัติ

สามชั้นพร้อมกัน: scan แท็ก <video> · hook fetch/XHR จับ .m3u8/.mpd/.mp4 · อ่าน performance resource-timing — เทคนิคเดียวกับส่วนขยายต้นแบบ

⬇ ปุ่มดาวน์โหลดในหน้าเว็บ

เลือก "ดาวน์โหลดอัตโนมัติ (ดีที่สุด)" หรือกด "รูปแบบ/คุณภาพ" เพื่อเลือกความละเอียด/ขนาดไฟล์จริงจากข้อมูลของ yt-dlp

📜 Log ละเอียด 3 ชั้น

app.log (หมุนเวียน 5MB×5) · downloads.log (output ของ yt-dlp ทุกบรรทัด) · events.jsonl (structured) ดูย้อนได้ในแอป + ส่งออก diagnostics เป็น zip

04ดาวน์โหลดและติดตั้ง

  1. ไปที่ หน้าดาวน์โหลด — หน้านี้ดึง release ล่าสุดจาก GitHub API อัตโนมัติ พร้อมปุ่มดาวน์โหลดและ SHA256 checksum
  2. เลือกไฟล์:
    • Windows: VDOGrabber-<เวอร์ชัน>-windows-x64.exe — ดับเบิลคลิกใช้ได้เลย ไม่ต้องติดตั้ง Python (ต้องมี WebView2 Runtime ซึ่งมีในตัว Windows 10/11)
    • Android: VDOGrabber-<เวอร์ชัน>-android.apk — ติดตั้งแบบ "อนุญาตแหล่งที่ไม่รู้จัก" ตามปกติ
  3. ครั้งแรกที่ดาวน์โหลดสตรีม HLS/DASH แอปจะดาวน์โหลด ffmpeg.exe ให้อัตโนมัติ (มี progress แสดง)
ตรวจความถูกต้องไฟล์: certutil -hashfile VDOGrabber.exe SHA256 แล้วเทียบกับ checksum บนหน้าดาวน์โหลด

05วิธีใช้

  1. เปิดโปรแกรม → พิมพ์ URL (หรือค้นหาคำ จะเด้งไป DuckDuckGo ให้)
  2. เล่นวิดีโอในหน้านั้น หรือกด 🔍 ตรวจหาวิดีโอ — ชิป 🎬 วิดีโอ N จะโชว์จำนวนที่พบ
  3. กด ⬇ ดาวน์โหลด หรือ รูปแบบ/คุณภาพ เพื่อเลือกเอง
  4. ติดตามใน ⚙️ → Control Center; ไฟล์จะอยู่ที่ Downloads\VDOGrabber

06สร้างจากซอร์ส (สำหรับนักพัฒนา)

# Windows Desktop
pip install -r requirements.txt
python app/main.py              # รันจากซอร์ส
python app/main.py --selftest   # ทดสอบ headless: engine + detection + ดาวน์โหลดจริง
python scripts/make_icon.py     # สร้างไอคอน (Pillow)
python scripts/build_exe.py     # แพ็ก dist/VDOGrabber.exe

# Android (หรือใช้ GitHub Actions ปั่นให้อัตโนมัติ)
cd android && ./gradlew assembleDebug

โครงสร้าง repo: app/ เดสก์ท็อป · android/ แอป Kotlin · docs/ เอกสาร+หน้าเว็บ · scripts/ เครื่องมือ build · code/ ต้นแบบศึกษา (ไม่ publish)

07ข้อจำกัดที่ควรรู้

ไม่รองรับ DRM (Widevine/Netflix ฯลฯ) และเนื้อหาหลังล็อกอินบางประเภท · บน Android ไฟล์ตรง (mp4/webm/mp3) ใช้ได้เต็มที่ ส่วน HLS/DASH แนะนำเดสก์ท็อป · YouTube เปลี่ยนบ่อย ให้กด "อัปเดต yt-dlp" ในแท็บตั้งค่าเมื่อเจอปัญหา
